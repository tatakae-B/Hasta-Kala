# Hasta-Kala Shop 🎨

**Hasta-Kala Shop** is a lightweight artisan billing and micro-sales analytics application designed specifically for small craft businesses and individual artisans. It bridges the gap between traditional craftsmanship and modern digital management.

---

## 🚀 Features

- **Quick Billing:** Streamlined checkout process for handmade products.
- **Sales Analytics:** Simple, visual insights into sales trends and revenue.
- **Inventory Management:** Track stock levels with automated **Low Stock Alerts**.
- **Best Seller Insights:** Identify your most popular items and colors.
- **Secure Data:** Built-in **App Lock** (Biometric/PIN) to protect business data.
- **Exportable Reports:** Generate and share **CSV and PDF** reports for accounting.
- **AI-Powered Insights:** Integrated with Gemini AI for smart business suggestions.
- **Multi-language Support:** Available in English, Hindi, Malayalam, Tamil, Kannada, and Telugu.

## 🛠️ Tech Stack

- **UI:** [Jetpack Compose](https://developer.android.com/jetpack/compose) (Modern Android UI toolkit)
- **Language:** Kotlin
- **Architecture:** MVVM with Clean Architecture
- **Dependency Injection:** Hilt
- **Database:** Room (Local storage)
- **Backend:** Firebase (Authentication & Cloud Sync)
- **AI:** Google Gemini API
- **Charts:** MPAndroidChart

## 📦 Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/tatakae-B/Hasta-Kala.git
   ```
2. **Open in Android Studio:**
   Import the project and wait for Gradle sync to complete.
3. **API Keys:**
   - Add your Gemini API key in `AIRepository.kt` or via `local.properties`.
   - Add your `google-services.json` from the Firebase Console to the `app/` directory.
4. **Build & Run:**
   Select a device/emulator and click the **Run** button.
